## Findings before changes

1. HIGH: Commons.I18n is absent on 4.0.4. Unconditional language lookup throws
   in Component.onCompleted before accumulator/backend initialization, leaving
   the real bar and home unavailable. Fix with optional host singleton and LANG.
2. Panel initially appeared absent during host load. A settled summon maps the
   keyboard panel on Virtual-1; no wrong-monitor defect reproduced. Keep checking
   after the compatibility repair and shell restart.
3. The installed host explicitly drops bar-widget payloads. Use actual panel
   navigation for live checks rather than promise unsupported shell payloads.
4. Shared Suflyor surfaces overlapped one baseline capture. Preserve that surface;
   keep full capture provenance and use plugin crops where unobscured.

Acceptance: no plugin language exceptions, real backend snapshot represented,
open/close/Escape, all section/form live captures, EN/RU text and visible focus,
static Node/Python/QML checks, unchanged mascot hashes, exact remote commit.
No VPN, real subscription/server data, verification/download or routing action.

## Additional live finding before correction

5. HIGH: navigating home while collection reads are pending showed "Not connected"
   together with the accent connection arc, "Handshaking with the server" and
   "Please wait". `HeroCard.busy` incorrectly included every backend busy flag.
   Collection refreshes are not VPN connection attempts. Restrict connection
   visuals to connecting/disconnecting and actual connection requests; retain
   disabled admission while a backend operation is busy. Live evidence:
   night-1-home.png (f1e585d), no VPN request was sent by the capture route.

6. MEDIUM: live Apps and Rules segmented choices lose label padding or clip long
   labels at equal half-widths on Quickshell 0.3.1. Use the native buttons' natural
   widths to stack choices only when the row cannot fit; keep short choices in a
   row and support vertical arrow keys for the stacked case.
7. MEDIUM: live Settings truncates bypass and DNS-lockdown labels before their
   meaning is complete. Shorten the control names and put the explanation in a
   wrapping description; preserve unsupported-state wording and configuration
   semantics. Evidence: night-1-apps.png, night-1-rules.png, night-1-settings.png.

8. MEDIUM: Free Pool's empty-state sentence overflows both sides of its card in
   the live EN theme. Give the real Text the card's available width and wrap it;
   check the other empty states for the same constraint. Evidence: night-1-free.png.
