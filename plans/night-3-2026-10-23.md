## Findings before repair

- Stock wtype waits for a compositor roundtrip between press and release. Native
  trace shows 0.427 to 1.094 seconds of Tab held, permitting auto-repeat. A
  task-process-only shim retains setup barriers and flushes key events without
  those per-event barriers. Its trace shows 2-7 ms pairs. No VM settings change.
  Inspected live before/first/second captures now show Name -> URL -> eye.
- Final-key captures can race virtual-device destruction. Repeat with a final
  sleep and slower capture spacing before treating later transitions as settled.
- The extended actual-QML test shows reverse Tab from Add does not return to
  the eye. TextField's unconditional input.forceActiveFocus() on scope entry
  overrides the chosen descendant. Test native focus-scope behavior by retaining
  input.focus=true and letting Qt choose the descendant on scope entry.
- An initial extended-test expectation incorrectly assumed Add was disabled.
  Source review and active-focus diagnostics disproved it: Add stays available
  for local required-field validation. Corrected the test, no product change.
