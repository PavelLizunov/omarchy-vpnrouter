# VPNRouter для Omarchy Quattro

Нативная QML-панель и виджет VPNRouter внутри оболочки Omarchy.
**Черновик разработки; полный паритет функций Linux пока не подтверждён.**

[English](README.md) · [Релизы](https://github.com/PavelLizunov/omarchy-vpnrouter/releases) (релиза плагина пока нет) · [Текущий статус](plans/current-status.md)

Плагин работает **без песочницы внутри общего процесса `omarchy-shell` с правами
вашего пользователя**. Такой же доступ получают его код и зависимости; проверка
Marketplace не является аудитом безопасности. См. [модель выполнения Omarchy](https://plugins.omarchy.org/develop.html).

## Установка

Нужны Omarchy Quattro и пакет Arch `vpnrouter-headless`.
См. [инструкцию пакета backend](https://github.com/PavelLizunov/VPNRouter/blob/dsh/omarchy-n4-lifetime/packaging/arch/README.md).
Выполните из репозитория на проверенном коммите:

С согласованным backend с user service плагин запускает systemd user service и
подключается к приватному сокету. Перезапуск оболочки отключает UI, а сервис
сохраняет сессию. Со старым пакетом или локальным payload используется stdio:
выход оболочки по-прежнему останавливает backend и разрывает соединение.
После подключения к сервису панель получает текущий сервер, время соединения
и счётчики TUN. См. [контракт сессии](plans/session-lifetime-candidate.md).

Для существующей установки сначала выполните [порядок обновления](docs/guide.ru.md#обновление-существующей-установки). Локальный backend плагина имеет приоритет над пакетом Arch и сохраняет stdio-поведение, пока не будет удалён.

```bash
id=io.github.pavellizunov.vpnrouter
plugin_dir="$HOME/.config/omarchy/plugins/$id"
mkdir -p "$plugin_dir"
git archive HEAD | tar --exclude='tests/fixtures/penguin_mascot_tile.png' -x -C "$plugin_dir"
omarchy plugin validate "$plugin_dir"
omarchy-shell shell rescanPlugins
omarchy plugin enable "$id" --section right
omarchy restart shell
omarchy plugin list --json
```

Используйте обычный каталог. Если локального payload нет, обёртка запускает
системный backend. Копирование файлов не устанавливает sing-box и не делает VPN
доступным само по себе. Необязательная [установка локального backend](docs/guide.ru.md#установка-и-настройка)
требует Python 3 и доверенной publish-директории; setup не скачивает бинарники.

Если служба сообщает о недостающих сетевых правах, выполните один раз в терминале:

```bash
sudo setcap cap_net_admin,cap_net_raw+ep /usr/lib/vpnrouter-headless/runtime/sing-box
```

Файловая система без расширенных атрибутов не сохраняет эти права; установите
пакет на файловую систему с их поддержкой. Для очистки DNS без запроса пароля
нужен актуальный пакет Headless. Setup и обёртка плагина не запрашивают права root.

## Использование

Нажмите значок в панели, чтобы открыть главную. Добавьте подписку или импортируйте
серверы, выберите сервер и нажмите «Подключить», когда backend разрешит подключение.
На главной кнопка подключения, статус и текущий сервер остаются над областью
прокрутки меню. Серверы прокручиваются под закреплённым поиском; форма импорта остаётся доступной
при раскрытой ошибке. В настройках
кнопки сохранения и отмены изменений закреплены внизу видимой страницы. На низком
экране дополнительная эмблема скрывается, а параметры маршрутизации доступны
в прокручиваемой области.

Правая кнопка на значке переключает соединение, средняя обновляет статус.
Разделы панели содержат серверы, подписки, приложения, правила маршрутизации,
профили, пользовательские конфигурации, настройки, диагностику и свободный пул.

Переключатель языка выбирает EN/RU/AUTO. Tab переносит фокус, Escape закрывает
панель. В многострочных редакторах отправка выполняется через Ctrl+Enter.
Базовый Test и HTTP Verify через прокси — разные операции; отсутствие значения
задержки не означает, что сервер недоступен.

[Руководство](docs/guide.ru.md) описывает команды открытия разделов, параметры,
установку, обновление, удаление и тесты; [архитектура](plans/implementation.md) — владельцев компонентов.

## Ограничения

Kill switch и DNS lockdown на Linux недоступны. Элементы DNS показывают сохранённую
конфигурацию, а не активное состояние ядра. Поиск работает по загруженным страницам;
списки загружаются по 100 строк. Технические сообщения backend могут оставаться
на исходном языке.

Автоматические проверки используют инертные ответы backend и offscreen-адаптер
host. Они не подтверждают работу живой оболочки, маршрутизацию VPN-трафика,
защиту от утечек или полный паритет функций. Открытые ограничения — в
[текущем статусе](plans/current-status.md).

## Удаление

Отключите VPN, затем удалите плагин:

```bash
omarchy plugin remove io.github.pavellizunov.vpnrouter
```

Выгрузка плагина отключает его клиент. Независимый сервис и данные VPN остаются;
остановка сервиса описана в руководстве.
См. [полное удаление и остановку backend](docs/guide.ru.md#удаление-плагина-и-остановка-бэкенда).
