# VPNRouter for Omarchy 2.51.0

| Component | Version |
| --- | --- |
| Omarchy plugin | `2.51.0` in [manifest.json](../../manifest.json) |
| Bundled VPNRouter Headless | `2.51.0-r1` |
| Arch package | `0.1.0.r86.ga97808f-1` in [bundle.json](../../backend/bundle.json) |
| sing-box-vpnctl | `1.14.4-vpnctl.2` |

The bundled backend requests and imports DNSTT profiles from compatible HTTPS
subscriptions. Refresh the subscription after updating the VPN component.
DNSTT links can also be imported directly. Quick Test explains when the
selected route requires a tunnel, including DNSTT and chained subscriptions.

A local backend added with `setup --backend-dir` takes priority over the Arch
package. Follow the [upgrade steps](../guide.md#upgrading-an-existing-installation)
to remove the local payload before switching to the new package. The package
update preserves VPN settings and subscriptions.

Plugin Control receives this version when the matching `v2.51.0` release is
published. The plugin and Arch package retain independent version sequences.

The bundled package passed live subscription import, DNSTT, chained HTTPS and
disconnect checks on an isolated Omarchy test machine. The Servers page was
checked with EN and RU labels and an inert protocol fixture. The chained
connection still timed out on the original workstation network.
