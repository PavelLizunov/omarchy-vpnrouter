# VPNRouter for Omarchy 0.1.3

Release scope for tag v0.1.3 in `PavelLizunov/omarchy-vpnrouter`.

## Version identity

- Product: the native Omarchy plugin in `PavelLizunov/omarchy-vpnrouter`.
- Plugin version: 0.1.3, owned by manifest.json.
- Backend: unchanged `0.1.0.r59.gf6b39db-1`, owned by backend/bundle.json.
- Runtime reference: current main `11feb675`, matching the accepted workstation
  runtime after the previously delivered Header/Hero filtering correction.

The 45 tracked runtime files match that local reference byte-for-byte. The plugin
manifest advances to 0.1.3 so this code can be distinguished from the older
v0.1.2 release by Plugin Control. Original artwork and the current penguin bar
mark are preserved. No other feature branch is included implicitly.

## Changes from v0.1.2

- Header/Hero mascot images decode at display density with smooth filtering and
  mipmaps, already present on main but absent from the immutable v0.1.2 tag.
- CI rejects a changed runtime or backend bundle under an already released
  plugin version. Documentation-only changes can retain their version.
- English/Russian README text distinguishes plugin, backend and release channel.

## Publication and limits

Plugin Control's stable update channel needs a published v0.1.3 release to receive
this version. The v0.1.2 tag remains immutable. Updating an active installation
is separate from publishing the plugin release.

The general bar icon still uses stepped pixel geometry; its visual complaint is
open and is separate from PNG filtering. Existing Linux kill-switch, DNS-lockdown
and live-acceptance limits remain documented in README.md. No new visual or VPN
acceptance is claimed by this version reconciliation.
